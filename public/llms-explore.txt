## Page Overview
The Explore page (`/?page=explore`) provides real-time search, category filtering, programming language filtering (`TypeScript`, `JavaScript`, `GLSL`, `Rust`, `Python`, `Go`, `Vue`, `Svelte`, `CSS`), and sorting (`Highest Confidence`, `Most GitHub Stars`, `Recently Updated`, `Alphabetical`) across 180+ verified websites and their public GitHub repositories.
